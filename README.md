# Dayflow — Human Resource Management System

> Every workday, perfectly aligned.

Dayflow is a modern, premium SaaS-style Human Resource Management System (HRMS) built to streamline core HR operations, employee onboarding, attendance tracking, and role-based data visibility.

---

## Features

- **Secure Authentication & Authorization**: Supabase Auth integration supporting secure user sign-up, sign-in, and session management.
- **Role-Based Access Control (RBAC)**: Strict segregation of duties between Employees and HR/Admin personnel.
- **Database-Level Security**: Protected via robust Supabase Row Level Security (RLS) policies to ensure users only access authorized data.
- **Modern Tech Stack**: Built for performance and aesthetics with Next.js App Router, Tailwind CSS, and shadcn/ui components.

---

## Tech Stack

- **Frontend**: Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, Lucide Icons
- **Backend**: Next.js Server Components, Server Actions
- **Database & Auth**: Supabase PostgreSQL, Supabase Auth, Row Level Security (RLS)
- **Deployment**: Vercel & Supabase (Free Tiers)
